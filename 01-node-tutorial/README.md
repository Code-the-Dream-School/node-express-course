 # Node Express Course - Lesson 1 Answers

This repository contains my solutions for Lesson 1 of the Node.js Express course.  
All exercises are implemented inside the `01-node-tutorial/answers` directory.

---

## Project Structure

- `03-modules.js` — Main module loader, requires other modules  
- `04-names.js` — Exports multiple values in an object  
- `05-utils.js` — Exports a single utility function  
- `06-alternative-flavor.js` — Exports multiple values with alternative syntax  
- `07-mind-grenade.js` — Module with internal logging function  
- `08-os-module.js` — Demonstrates usage of Node's built-in OS module  
- `09-path-module.js` — Demonstrates usage of Node's built-in Path module  
- `10-fs-sync.js` — Uses synchronous FS methods to write/read a file  
- `11-fs-async.js` — Uses asynchronous FS methods with callbacks  
- `12-http.js` — Simple HTTP server listening on port 3000  
- `prompter.js` — Simple server to accept form input and display it  

The `temporary/` folder contains temporary files created during FS operations. It is gitignored.
